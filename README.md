# 🕊️ Catechesis Backend

Backend desarrollado con **FastAPI** para la gestión integral de estudiantes, padres y sacramentos dentro de un sistema parroquial de catequesis.  
El sistema permite registrar, actualizar y consultar información relacionada con los estudiantes, sus representantes y los sacramentos recibidos.

---

## 🚀 Tecnologías Utilizadas

- **Python 3.11+**
- **FastAPI** — Framework principal para la API REST
- **SQLAlchemy ORM** — Modelado de base de datos
- **PostgreSQL** — Motor de base de datos
- **Alembic** — Migraciones de esquemas
- **Pydantic** — Validación de datos
- **Uvicorn** — Servidor ASGI para desarrollo
